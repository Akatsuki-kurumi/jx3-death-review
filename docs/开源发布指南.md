# 开源发布维护

当前版本 v0.2.0，仓库 Akatsuki-kurumi/jx3-death-review，原创代码 MIT。

1. 阅读 THIRD_PARTY_NOTICES.md，区分原创代码、监控字典和第三方打法参考的来源与许可。
2. 仅提交公开源码、运行所需编译数据、合成测试和公开文档。禁止提交用户配置、凭据、日志、报告、对话、学习经验、头像、缓存、研究材料和测试截图。
3. 从审计后的暂存索引或提交导出干净源码，安装锁定依赖并运行 pnpm test。默认测试无需个人 JCL；可选真实日志测试没有样本时跳过。
4. 在干净源码执行 pnpm package:open-source。输出为 dist/open-source/v0.2.0/，打包脚本排除头像、ICO 和本机缓存。开源发行默认使用独立的 ZheZhaSiDe-OpenSource 用户数据目录，不导入原版设置。
5. 审计 app.asar 和 ZIP：没有配置、密钥、日志、报告、学习经验或头像；manifest 为正确版本及 open-source 发行类型。保留全部 Electron 运行文件和许可证。
6. 验证空配置首次启动，压缩完整应用目录，并生成 SHA256SUMS.txt。GitHub Release 只上传开源 ZIP 和校验文件，附中文更新说明；不要上传本地原版或旧 ZIP。
7. 确认远程分支与目标提交，提交、推送并创建对应版本标签；不得重写既有 Release 标签。本地原版覆盖仅在用户明确要求时执行，并保留可恢复的旧文件备份。

运行配置由使用者自行填写；开源版之后保存的是其自己的配置，并非每次启动重置。清理发布内容不能删除维护者真实用户数据。
