# 模型供应商配置指南

适用应用版本：**v0.2.0**。检查日期：**2026-11-04**。

AI 分析是可选功能。应用已接入 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 三种协议，并提供下表中的供应商预设。**已完成的是预设地址、协议适配和模拟模型流程检查；尚未逐家使用真实供应商账号完成连通性及报告质量验收。** 预设存在不代表账号已开通该模型，也不保证同平台所有型号都兼容。

## 怎样配置

1. 在初次引导的 AI 模型配置页，或对局列表右上方的“修改 AI 配置”中，选择模型供应商。
2. 核对 **Base URL**。预设会填入常用地址；不同地区、工作空间、订阅套餐或中转服务可能需要另一个地址。
3. 填写供应商控制台提供的**模型 ID**，不是网页聊天产品的显示名称。选择能处理文本、较长上下文和多轮工具调用的模型；不使用图像生成、语音或嵌入模型。
4. 填写该地址所属平台的 **API Key** 并保存。密钥输入为密码框；更换域名、端口或 URL 协议时必须重新填写对应密钥。同一来源显示“已安全保存”时，留空可保持原密钥。
5. 进入某局的“击杀分析”，主动点击“AI 分析”。保存配置、打开历史报告和拖动时间轴不会自动生成报告。首次分析会进行多轮取证，需要一些时间；报告下方可继续追问。

请从所选平台的 API 控制台取得地址、模型 ID 和密钥，不使用聊天网页登录密码或会话令牌。普通 API、订阅套餐与地区账号的权限和地址应按该平台说明核对。

## 高级连接选项

通常沿用预设即可。出现协议或参数错误时再展开“高级连接选项”。

| 选项 | 用法 |
| --- | --- |
| 接口协议 | 选择服务实际支持的协议。基础地址和完整接口地址均可填写，例如 `https://api.openai.com/v1/responses`；应用不会重复拼接，但完整地址与所选协议冲突会报错。自定义服务的“自动”通常落到 Chat，不能识别任意私有接口。 |
| 使用流式传输 | 本版仅支持 Chat 流式；千问、硅基流动预设开启。模型要求流式时可启用，报告仍在完整接收并校验后显示。Responses 和 Messages 使用非流式响应。 |
| 输出参数名称 | 仅适用于 Chat，可选自动、`max_tokens`、`max_completion_tokens`。遇到不支持参数的提示时按供应商要求调整。 |
| 单次输出上限 | 留空使用应用预算，或填 1024–65536 之间的整数，且不得超过所选模型限制。该值只限制单次输出，不会扩大整个分析任务的预算。 |

本版不提供 Azure 旧式 deployment/api-version、AWS Bedrock SigV4 或 Google Vertex 服务账号认证，也不覆盖多模态、实时语音或任意网关的私有扩展。

## 实际检查过什么

**真实模型记录：** 项目在此前的实机验收中使用过 **MiniMax-M3**，完成过单局取证、报告生成与证据核对，也遇到过输出截断和引用校验失败。这是特定账号、型号和样本的历史结果，本次没有重新付费调用；不能据此推断新版本的每一局、MiniMax 的其他型号或其他平台均已实测。

本版本的兼容性检查使用隔离配置和模拟 HTTP 响应，不调用付费模型：

- 有固定地址的供应商预设均检查了接口地址拼接；Chat 预设检查了工具往返时保留推理上下文和供应商附带签名。百炼地址由用户填写，其兼容路径按通用 Chat 适配处理，未验证用户工作空间。
- Chat、Responses、Messages 三种协议分别走过正式 Agent 的多轮取证、成文、证据校验和报告缓存流程。
- 检查了 Claude 原生多工具结果转换，Chat 流式中文拆包、并行工具参数、输出截断、取消、错误信息和输出限制。
- 配置保存与重读使用独立临时用户目录；检查了 Windows 加密往返、跨来源密钥保护和同源限制。

可在源码目录复现上述 14 项检查：

```powershell
node --test test/ai-multi-provider.test.cjs test/ai-provider-flow.test.cjs
```

**未验证范围：** 各供应商真实账号的权限、余额、地区网络、全部模型能力与最终分析质量。模拟测试通过不等于模型会稳定作出正确的游戏判断。协议层兼容也不能解决模型本身不支持多轮工具、输出限制过小或证据推理不足的问题。

## 常见问题

| 提示 | 优先检查 |
| --- | --- |
| HTTP 400 / 422 | 查看应用给出的参数提示；核对接口协议、模型 ID、输出参数、输出上限及是否要求流式。400 不一定是密钥错误。 |
| HTTP 401 | 密钥是否有效，地址是否与密钥的平台、地区和套餐对应。 |
| HTTP 403 | 账号权限、模型访问权限或供应商限制。 |
| HTTP 404 | Base URL 是否填成控制台网页，路径是否正确，模型或接入点 ID 是否存在。 |
| HTTP 429 | 额度、并发或调用频率；根据平台提示等待或调整。 |
| 超时、输出截断、报告校验失败 | 先查看具体提示。可能是网络、单次输出限制、模型返回格式或证据引用问题；不能仅凭此判断密钥失效。截断内容不会当作完整正式报告。 |

密钥由应用后端使用 Windows 当前用户 DPAPI 加密保存，不进入报告、提示词或学习经验。主动生成分析或发送追问时，必要的战斗片段会发给配置的供应商；接收方的数据处理规则由该供应商决定。提交问题时只提供脱敏后的错误提示与配置类型，不公开密钥或私人战斗日志。
