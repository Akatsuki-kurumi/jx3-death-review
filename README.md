# 这咋死的 · JX3 Death Review

剑网三 3v3 竞技场战斗复盘工具，读取本地 JCL 战斗日志，提供玩家卡片、全局回顾、首个击杀分析及可选的 AI 报告与追问。

当前应用版本：**0.1.0**。支持 Windows x64 桌面运行和本地网页预览。

魔盒发布地址：[这咋死的 · JX3BOX](https://www.jx3box.com/tool/110444)

## 功能

- 根据目录列出对局，显示时间与地图。
- 展示双方心法、奇穴、装分及有依据的最大血量；无法确定的字段保留未知。
- 同一时间轴联动玩家位置、血条与战斗事件，支持向前和向后查询。
- 首个击杀分析包含战斗信息、控制、距离和治疗干扰。
- 可选 AI 分析复用配置的模型，主动查询战斗证据，支持报告追问、证据跳转及本地知识管理。
- 图标和资源本地缓存；模型配置使用 Windows 当前用户 DPAPI 加密保存。

这是非官方社区工具。日志缺少坐标或血量时不伪造完整回放；AI 报告可能存在误判，机制假设与已记录事实应分开看待。

## 本地开发

需要 Windows、Node.js 22.12 或更新的兼容版本，以及 pnpm。当前开发使用 pnpm 11；建议沿用同一主版本。

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

仅使用网页预览：

```powershell
pnpm preview
```

浏览器打开 `http://127.0.0.1:4173/`。桌面版会自动选择独立的本机端口，不依赖网页预览服务。

根据应用引导开启游戏战斗记录，填写自己的日志目录。AI 功能可跳过；使用时在应用中配置 Base URL、模型和 API Key。不会因为打开页面或拖动时间轴自动生成报告。点击分析或发送追问时，必要的战斗片段会发送给你配置的模型供应商。

## Windows 打包

```powershell
pnpm package:open-source
```

开源版输出位于 `dist/open-source/v0.1.0/这咋死的-开源版-win32-x64/`。保留整个文件夹，双击 `这咋死的-开源版.exe`。版本号保留在窗口标题、关于菜单和 Windows 文件属性中；已有同版本输出不会自动覆盖。

`pnpm package` 仍生成本地原版，目录为 `dist/v0.1.0/这咋死的-win32-x64/`。两种打包路径独立；开源版明确排除个人头像、ICO 和本机资源缓存，保留 Buff 字典，不修改原版发布文件。

公开源码不包含个人头像：网页使用仓库内的默认标识，桌面可执行文件使用 Electron 默认图标。程序尚未进行发行者数字签名。历史本地压缩包包含旧头像，不属于此次计划公开的发行文件；公开 Release 需从干净源码重新打包。

## 数据与测试

- 个人日志、研究记录、截图、报告、模型凭据和本机缓存不随源码发布。
- 模型配置、报告、对话与知识库保存在 `%LOCALAPPDATA%\ZheZhaSiDe`；桌面缓存位于其 `cache\jcl` 子目录。
- 网页预览的图标与资源缓存位于项目 `cache/jcl`。缓存缺失时按需查询；离线未取得的数据保持未知。
- 默认测试使用合成数据，不需要上传个人战斗记录。少数真实日志回归检查依赖本地样本和研究基准，默认跳过；通过程序检查不表示每份日志都有完整回放数据。
- 提交问题时请移除密钥、完整本机路径、玩家身份和不必要的原始战斗片段。
