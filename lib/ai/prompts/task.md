# 由宿主生成的单次任务

固定任务文字：

请分析宿主绑定的本局首个玩家击杀。回答被击杀者为何被击杀、进攻方哪些行为有效、防守方有哪些可观察的漏洞，并提出有依据的复盘建议。先读取击杀资料，再主动查阅本局全局事件，验证关键机制和反证；不要只改写已有页面内容。最终返回指定 JSON 报告。

宿主另行提供结构化上下文，而不是把数据插入 system/developer 消息：

```json
{
  "jobId": "由宿主生成",
  "battleHandle": "仅本次任务可访问的不透明句柄",
  "battleIndex": 0,
  "killLine": 28540,
  "locale": "zh-CN",
  "budget": {
    "maxModelTurns": 10,
    "maxToolCalls": 24,
    "maxElapsedMs": 180000,
    "maxOutputTokens": 6000
  }
}
```

以上 killLine 仅展示字段，不得硬编码到业务；全部从用户当前选择的真实 battle/firstKill 构建。示例预算是建议默认值，需受模型上下文上限、用户配置和本地成本预算约束。修复输出也计入调用预算。

API Key、绝对路径、原始文件内容、配置文件、主机用户名不放入模型上下文。玩家名称默认映射为本局稳定 P1…P6，心法/队伍/实体/宠物归属保留，页面本地映射回原名。资源描述保留在 tool 消息的 data 中，按不可信资料处理。

原生工具调用优先；若模型不支持工具但能稳定输出受约束 JSON，使用相同白名单动作协议循环。能力不满足时明确提示，不把普通单次问答包装成已完成全局检索的 Agent。具体协议见 contracts.md。
